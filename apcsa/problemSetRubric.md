The letter is for the overall level. A **plus or minus shows where the work falls within that level**.

| Grade | General description |
|---|---|
| **A+** | Complete, consistently accurate, and shows especially thoughtful solutions. |
| **A** | Complete or nearly complete; strong understanding with minor errors. |
| **A−** | Strong understanding overall, with a few gaps or incomplete responses. |
| **B+** | Mostly complete and correct; a few noticeable misunderstandings. |
| **B** | Mostly complete; solid understanding with some errors. |
| **B−** | Generally understands the material, but errors or omissions are recurring. |
| **C+** | Shows understanding in several areas, with significant gaps elsewhere. |
| **C** | Substantial work completed; partial understanding and frequent errors. |
| **C−** | Some meaningful work, but major gaps in completion or understanding. |
| **D+** | Limited work demonstrating some understanding. |
| **D** | Much is missing or incorrect; little evidence of understanding. |
| **D−** | Minimal meaningful work or understanding demonstrated. |
| **F** | Little or no meaningful work submitted. |
