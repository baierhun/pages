# Java Classes & Objects

Fill in the blanks as we learn each term.

### 1. Class

A **class** is a blueprint or template for creating __________.

**Example:** `Car` could be a class.

---

### 2. Object

An **object** is a specific thing created from a __________.

**Example:** A particular red Honda could be an object of the `Car` class.

---

### 3. Instance

An **instance** is another word for a specific __________ created from a class.

**Example:** `myCar` is an instance of the `Car` class.

---

### 4. Instantiate

### 5. Parameters
