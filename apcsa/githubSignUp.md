# How to Get Your GitHub Student Benefits

GitHub offers verified students **free access to GitHub Pro, GitHub Copilot, GitHub Codespaces, and many other developer tools** through the GitHub Student Developer Pack.

You will need a GitHub account and proof that you are currently a student.

---

## Step 1: Create a GitHub Account

If you don't already have a GitHub account, go to:

[github.com](https://github.com?utm_source=chatgpt.com)

Click **Sign up** and create a free account.

### Important

* Use your **real name** on your account.
* Choose a professional username. This will be visible to others.
* Use an email address that you can access.
* **Never share your GitHub password with anyone.**

If you already have a GitHub account, **do not create another one**. Use your existing account.

---

## Step 2: Apply for GitHub Education

Go to:

[GitHub Education Student Benefits](https://github.com/settings/education/benefits?utm_source=chatgpt.com)

Under **GitHub Education**, click **Start an application**.

GitHub will ask you for information about your school and your student status.

You will need to provide:

* Your school
* Your expected graduation year
* Your current student status

---

## Step 3: Verify That You Are a Student

GitHub may ask you to verify your student status using your **school email address** or by providing documentation.

Possible forms of documentation include:

* A current school ID
* Your class schedule
* A transcript
* An enrollment verification letter

Your documentation needs to clearly show that you are **currently enrolled as a student**.

### If GitHub asks for a school email

Add your school email address to your GitHub account and verify it before continuing with your application.

---

## Step 4: Submit Your Application

Review your information and click **Submit application**.

GitHub will review your application. **Approval may take some time**, so you may not receive your benefits immediately.

If GitHub asks you for additional information, follow the instructions provided.

---

# Step 5: Activate GitHub Copilot

Once your student application has been approved, you need to activate your Copilot benefit.

Go back to:

[GitHub Education Benefits](https://github.com/settings/education/benefits?utm_source=chatgpt.com)

Under **Free GitHub developer resources for students and teachers**, click **Learn more**.

Follow the instructions to activate **Copilot Student**.

### What do you get?

Verified students receive **free GitHub Copilot**, including premium features. The current student plan includes unlimited code completions along with an allowance of AI credits and limited chat/agent usage.

**You should NOT enter a credit card or purchase a paid Copilot plan.**

> **Important:** Your GitHub Education approval and Copilot activation are separate steps. Copilot may take a few days to become available after your student verification is approved.

---

# Step 6: Check Your GitHub Benefits

Once everything is approved, you can return to your GitHub Education benefits page to see the tools available to you.

Verified students currently receive benefits including:

* **GitHub Pro**
* **GitHub Copilot**
* **GitHub Codespaces**
* Other tools and services through the Student Developer Pack

GitHub currently provides verified students with **up to 180 core-hours of Codespaces use per month** on their personal accounts.

---

# You're Done!

Before moving on, make sure you have:

* [ ] Created a GitHub account
* [ ] Verified your email address
* [ ] Applied for GitHub Education
* [ ] Been approved as a verified student
* [ ] Activated GitHub Copilot
* [ ] Confirmed that GitHub Codespaces is available
* [ ] Written down your GitHub username

**Do not give your GitHub password to anyone, including your teacher.**

If you have trouble getting verified, **show your teacher the message GitHub gives you** so we can figure out what went wrong.
