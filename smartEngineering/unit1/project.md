# Unit 1 Final Project

## Smart Appliance Prototype

### Today's Challenge

Today you will use the project format you have learned to design a **control panel for a household appliance**.

Choose an appliance such as:

* Coffee maker
* Washing machine
* Microwave
* Dishwasher
* Air purifier
* Fan

**You are not building the appliance. You are building its interface.**

Your prototype should show how a user would control the appliance using **physical inputs** and how the appliance would respond using **physical outputs**.

---

# Your Goal

Create a working **smart appliance control panel** that uses:

**3 inputs**

and

**3 outputs**

Your inputs and outputs should work together to create a believable appliance control panel.

---

## Example: Coffee Maker

### Inputs

| Input         | Purpose              |
| ------------- | -------------------- |
| Button        | Start Brew           |
| Button        | Cancel               |
| Potentiometer | Select Brew Strength |

### Outputs

| Output    | Purpose               |
| --------- | --------------------- |
| Green LED | Brewing               |
| Red LED   | Cancelled / Not Ready |
| Buzzer    | Brewing Finished      |

The goal isn't to make a real coffee maker.

The goal is to create a **physical interface that communicates what the appliance is doing**.

---

# Think Like a Designer

Before you build, decide:

### What does the user control?

What actions should the user be able to perform?

### What does the appliance communicate?

How will the appliance tell the user what is happening?

### How do the inputs and outputs work together?

What happens when each input is used?

What output or outputs should respond?

---

# Project Requirements

Your prototype must:

1. Represent a **household appliance**.
2. Include **3 different physical inputs**.
3. Include **3 physical outputs**.
4. Give each input a clear purpose.
5. Give each output a clear purpose.
6. Have the inputs and outputs interact in a meaningful way.
7. Use the components safely and correctly.
8. Be built on a breadboard.
9. Be able to be demonstrated to the teacher.

---

# Individual Project Check

When your prototype is complete, you will demonstrate it **individually** with the teacher.

You should be able to explain:

### Your Appliance

* What appliance did you choose?
* What does your interface control?

### Your Inputs

* What are your three inputs?
* What does each input do?
* Why did you choose each input?

### Your Outputs

* What are your three outputs?
* What does each output indicate?
* How does each output respond to an input?

### Your Circuit

* Where is **5V** connected?
* Where is **GND** connected?
* Why does an LED need a resistor?
* How are your components connected?
